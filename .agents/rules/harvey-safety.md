# Harvey Safety Invariants & Operational Rules

These rules represent non-negotiable architectural and operational invariants for Harvey. Any automated agent, developer, or background task operating on this codebase must strictly adhere to them.

## 1. Strict Deliverability & Recipient Verification
- **Never send emails to addresses tagged `guess` or `invalid`.**
- Outbound cold emails must only be sent to prospects with `email_status = 'verified'` (or explicitly configured `risky` catch-all domains when `channels.email.send_to_risky: true` is enabled in `harvey.yaml`).
- Guessed email addresses generated by pattern heuristics must remain tagged as `guess` until verified through an integrated email verification service (e.g., Reoon, ZeroBounce, Hunter).
- Never modify, bypass, or weaken the deterministic pre-send safety checks in `harvey/gate.py` and `harvey/agents/sender.py`.

## 2. Outbox Approval Queue Enforcement
- **Never bypass the outbox approval queue unless explicitly configured.**
- Outgoing emails generated by campaigns or reply handlers must be staged in the `outbox` table with status `pending_review` by default (`channels.email.require_approval: true`).
- Outbox messages require explicit human approval via the dashboard or `harvey outbox --approve <id>` / `harvey outbox --approve-all`.
- Autopilot sending (`approved` status on initial staging) is permitted only when `channels.email.require_approval: false` is explicitly set in configuration.
- Never write scripts or background logic that auto-approves or force-drains the outbox around the human review ladder.

## 3. Python Environment & Execution Isolation
- **Always run Python commands inside the local `.venv` (Python 3.11+).**
- Harvey requires Python 3.11 or newer (`requires-python = ">=3.11"`). System Python versions below 3.11 are strictly unsupported and will fail due to union typing (`X | Y`) and modern standard library dependencies.
- All CLI commands, background runners, package installs, and test suites must run using the virtual environment interpreter (`.venv/bin/python`, `.venv/bin/harvey`, `.venv\Scripts\python.exe`, or `.venv\Scripts\harvey.exe`).
- Never run commands against system Python or global pip environments.
